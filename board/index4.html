How to use Manipulatives

Add Cards: Use the + Add button. Separate items with commas. Use a colon (:) to make a two-sided card (e.g., Flash:Card).

Share: Click "Share Link" to copy a URL that opens with your current set of cards.

Move: Drag cards around. Double-click to flip.

Keyboard Shortcuts:

A: Add Cards
P: Present Mode
B/I/U: Style
F: Cycle Font
G: Cycle Canvas
R: Shuffle
L: Line
T: Stack
S: Share
C: Clear
PgUp/PgDn: Resize
H: Help
- or Z: Toggle Cloze
Ctrl+Z: Undo
